# Исследования: аудит и проверка соответствия

Исходная ревизия: `4b36e18`, 25 октября 2026.

Обнаружено до изменений:

- Ошибка чтения одного каталога заменяла оригинальное дерево девятью демонстрационными технологиями.
- Импорт сохранял только первый `folder`, терял коэффициенты `path`, `sub_technologies`, исходные условия и сложные эффекты.
- Все входящие `path` превращались в AND-зависимости; альтернативные пути требовали всех предшественников.
- Начальная история всегда вычислялась на 1936.01.01; неизвестные условия и проблемы истории терялись.
- Страны без прочитанной истории получали одинаковый выдуманный запас из трёх слотов.
- `enable_building = { building=... level=... }` разбирался как список имён.
- Идеи, источники скриптовых бонусов, специальные проекты и современные доктрины не были связаны с исследованиями.
- Прогресс отменённой технологии исчезал; отдельного снимка исследований не было.
- Промышленные технологические эффекты не доходили до ежедневного производства/строительства.
- Дерево пересчитывало список узлов и ETA каждый кадр, не поддерживало масштабирование.

Данные установленной HOI4 пользователя в этой среде отсутствуют. Число проверенных реальных технологий: **0**, стран: **0**. Синтетические регрессионные тесты проверяют движок, но не доказывают совпадение с HOI4. Точная формула/округление закрытого движка требуют сравнительных замеров на экспортированной версии.

Для проверки схем изучены cwtools-hoi4-config (297dd69), Jomini, hoi4lint, tree-sitter-HoI4 и TranslatorHoi4. Nova/HOI4-Modding-Suite использован только как визуальная справка: его лицензия CC BY-NC-ND 4.0 не разрешает перенос производного кода. Код этих проектов не скопирован.

## Локальный экспорт на Windows

После `git pull --ff-only` открой PowerShell в папке **с Cargo.toml**:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Export-Hoi4Research.ps1
```

Уже задан путь `E:\перекид с ссд\games\Hearts of Iron IV`. Скрипт находит проект относительно собственного расположения и не зависит от текущей папки `C:\WINDOWS\system32`. Требуются установленный Rust/Cargo и доступ к игровым файлам. Python и Jomini CLI не нужны.

Для известных активных DLC используй **точные названия из своей игры**:

```powershell
.\tools\Export-Hoi4Research.ps1 -EnabledDlc @('точное имя DLC 1','точное имя DLC 2') -Scenario 1936
```

Для игры без DLC:

```powershell
.\tools\Export-Hoi4Research.ps1 -NoDlc -Scenario 1939
```

Если выбор DLC не задан, он отмечается как неизвестный: наличие установленных файлов не доказывает, что DLC включён и доступен аккаунту. Условие `has_dlc` в исследовательском движке в таком профиле возвращает unknown. Нужна повторная выгрузка с правильным выбором; legacy-ветка не считается подтверждённой.

`-DataLayers` принимает **распакованные каталоги** DLC/модов в фактическом порядке загрузки, от более раннего к более позднему. Автоматического угадывания порядка архивов/модов нет. Поддерживается замена файлов по относительному пути и `replace_path` из `descriptor.mod`. Зависимости модов, содержимое DLC-архивов и launcher playset самостоятельно не реконструируются.

Экспорт сохраняется в `data/hoi4`, предыдущая папка переносится в соседнюю `hoi4-backup-<timestamp>`. Карта (`provinces.bmp`, `rivers.bmp`, определения/соседства), текстовые common/history/events/localisation/interface и обычные флаги TGA копируются из установленной игры. Произвольные изображения/звуки не включаются. В `.gitignore` исключён весь `data/`: закрытые файлы и полученный реестр не публикуются вместе с кодом.

Получаются:

- `data/hoi4/research-import.json`: версия из EXE/launcher metadata, SHA-256 EXE, доступные описания DLC, явный выбор DLC/слоёв/сценария. Checksum HOI4 остаётся unknown, пока не передан `-Checksum` из оригинальной игры; SHA-256 EXE не называется checksum игры.
- `data/hoi4/cache/research-registry-v4.bin`: заголовок формата, сжатый zlib JSON с готовым реестром/AST/историями. При запуске проверяются состав, размеры и время изменения входных файлов; неизменённые тексты повторно не парсятся.
- `data/hoi4/research-report.json`: полный набор ID и определений, правила и их исходные файлы, стартовые данные всех стран на найденные сценарии, неисполненные эффекты/ограничения и диагностика.
- `data/hoi4/research-review.zip`: отчёт и сжатый реестр для передачи и сверки. Это локальные игровые данные пользователя, не содержимое публичного репозитория.

Версия и настройки задают источник данных, но не доказывают соответствия закрытому движку. Поля отчёта `parity_verified=false`, `original_game_timing_comparisons=0` остаются честными до сравнения с оригинальной игрой.

Повторный импорт и сборка:

```powershell
cargo run --release --bin hoi4-research -- import data/hoi4
cargo test --all-targets
cargo check --all-targets
cargo run --release --bin hoi4-mobile
```

Обычный `cargo run --release` также запускает игру (`default-run`).

## Выполняемые условия и эффекты

Поддержаны AND/OR/NOT/NOR/NAND; текущий и original tag, дата, DLC, технологии, фокусы, идеи, государственные/глобальные флаги, идеология, известное членство во фракции, военное/зависимое состояние, правила и простые числовые переменные. Параметрически несложные scripted triggers разворачиваются один раз при импорте. Чужие country scopes, PREV, неизвестные факты и сложные scripted triggers не подменяются контекстом текущей страны.

Военное состояние обновляется из существующей боевой системы. Фракции/зависимость/правила должны быть предоставлены соответствующими подсистемами; их отсутствие означает unknown. Не реализованная дипломатия не создаёт ложные факты «страна точно не во фракции».

Исполняются `set_technology` (включая 0 и уровни), `add_tech_bonus`, `set_research_slots`, `add_research_slot`, флаги, идеи и их смена, базовые переменные, участие/бонусы в tech-sharing groups, условные if/else, простые scripted effects. Разовый бонус сохраняется с выбранным исследованием и не расходуется повторно при возобновлении. Сложные эффекты и превышение рекурсии сохраняются с исходным AST и причиной неисполнения.

Награды фокусов/событий/решений и on_actions хранятся как источники, но **не выдаются при одном лишь чтении файлов**. `ResearchWorld::execute_source` — точка вызова внешним движком после соответствующего игрового события. Завершённый фокус помечается и не выдаёт награду повторно. Полного планировщика фокусов, событий, решений и on_actions в игре пока нет; интерфейс этих механик остаётся заглушкой.

Потребители эффектов:

- Наземное оснащение/подразделения/тактики и поддерживаемые характеристики дивизий — через единый реестр и существующую агрегацию армии.
- Выпуск военных заводов, потолок/рост/начальная производственная эффективность — через ProductionRules страны.
- Общая/специализированная скорость стройки, глобальные строительные слоты и `enable_building` с настоящим уровнем — через правила страны и существующие очереди.
- Скорость исследований, категорийные бонусы идей и обмен — через дневной шаг слота.
- Модули конструкторов, авиационные/морские/другие отсутствующие потребители и неизвестные модификаторы сохраняются, но отмечаются неисполненными. Получение ID модуля не выдаётся за работающий конструктор.

## Что ещё нельзя считать выполненным

- Число прочитанных **реальных** технологий и историй из установки пользователя в этой среде: **0 / 0**. Локальные тестовые наборы созданы самостоятельно и не представляют историческую Германию или другую страну HOI4.
- RNG/округление/очерёдность и выбор бонуса закрытого движка, правила сохранения/переключения прогресса и даты завершения не сопоставлены с реальной игрой. Текущая политика выбирает лучший из подходящих бонусов по эффективной скорости на дату назначения; её точное соответствие HOI4 не доказано.
- `BASE_TECH_COST`, AOT penalty и запас дней читаются из буквальных Lua defines. Не прочитанные коэффициенты перечислены в отчёте как непроверенные базовые значения. Lua-выражения не исполняются. Выражения в стоимости/годе/коэффициенте пути должны быть разрешены; неизвестное значение блокирует исследование, а не получает выдуманный результат.
- Современные doctrine folders/tracks/grand doctrines/subdoctrines и специальные проекты импортируются отдельно с исходными определениями. Их полноценные XP/mastery/учёные/объекты/этапы/оборудование/прорывы пока не реализованы. Такие технологии нельзя начать как обычное исследование за дни. Конкретный игровой цикл нужно выбирать после чтения версии/DLC установки.
- Полная GUI-геометрия и оригинальные иконки/звуки/анимация не воспроизведены. Relevant `.gui` AST сохраняется; текущий отрисовщик использует несколько folder/position из технологий и собственные обозначенные заглушки изображений, не выполняет универсальный GUI binding.
- `save_snapshot` / `load_snapshot` сохраняют весь компонент исследований: страны, уровни, слоты, прогресс, припаркованные исследования, бонусы, sharing, модификаторы, флаги и отложенные эффекты. Проверяется fingerprint реестра. Это **не полное сохранение кампании**; GameSession разрешает восстановить компонент только на той же дате/часе, чтобы не откатывать отдельно исследования относительно экономики/войны.
- Полная стратегическая AI-логика не воспроизведена: исходные AI-поля сохранены, автоматический выбор пока использует статический вес и доступность.
- Android на устройстве не проверялся; проведены headless Rust-проверки и нативная Linux GPU-проверка интерфейса.

## Проверка

Регрессии покрывают AST/кавычки/предел вложенности, несколько folder и дробные координаты, переменные стоимости, альтернативные пути/скрытые ветки/XOR, независимое состояние стран и даты 1936/1939, однократное расходование награды, отмену/возобновление и неуспешное переключение без потери состояния, sharing, завершение/снятие технологии без удвоения модификаторов, неизменённый кэш и replace_path, round trip снимка и отказ чужому fingerprint, реальные выходы производства/стройки/армии и блокировку отдельной подсистемы доктрин/проектов.

Нативная проверка на авторском наборе: запуск исследования, прогресс, переключение/возврат, завершение, причины недоступности, зум и ширины 360/600/1280/1920. Экспортёр пройден целиком на том же синтетическом наборе, включая оба сценария и сжатый реестр. Эти проверки не являются сравнением с оригинальной HOI4.
